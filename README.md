**A free, 30-day Python course for beginners that runs entirely in the browser.** No installation, no account: open the link and start writing Python on Day 1.

## What you get every day

- A short explanation with runnable examples
- A step-by-step **visualizer** that shows what the code does line by line
- Guided practice, then **auto-checked problems** with several model solutions
- A quiz, a puzzle, spaced-repetition review cards, and a place for your notes

Plus a free **playground**, a bilingual **glossary** (English + Arabic), printable **weekly cheat sheets**, and a personal **certificate** after Day 30.

## The 30-day plan

| Week | Theme | Topics |
| --- | --- | --- |
| 1 | First steps | `print`, variables, input and math, strings, decisions |
| 2 | Loops and collections | `while`, `for`, lists, tuples, sets, dictionaries |
| 3 | Organize like a pro | functions, modules, errors, files, classes, inheritance |
| 4 | Algorithms and AI | searching and sorting, NumPy, machine learning with scikit-learn, text AI |
| Days 29–30 | Capstone | a text adventure, a library system, or an AI classifier — then the certificate |

Suggested pace: about two hours a day — five lesson days, one review/project day and one rest day each week.

## How it works

- Python runs in the browser (Pyodide, loaded from the jsDelivr CDN on first use).
- Progress, code and notes are saved in the student's own browser. Nothing is sent to a server.
- The whole site is static HTML, CSS and JavaScript, published with GitHub Pages.
