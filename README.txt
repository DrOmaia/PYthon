Py30 — Learn Python in 30 days (online edition)
=========================================

ONLINE EDITION (for GitHub Pages or any static web host)
Upload the contents of this folder (index.html at the root) and open the site.
Python runs in the browser; it is loaded from the jsDelivr CDN on first use.
Progress is saved in each student's browser.

COMPLETE COURSE: all 30 days.
  Week 1  First steps: print, variables, input and math, strings, decisions
  Week 2  Loops and collections: while, for, lists, tuples, sets, dictionaries
  Week 3  Organize like a pro: functions, modules, errors, files, classes, inheritance
  Week 4  Algorithms and AI: searching and sorting, numpy, machine learning, scikit-learn, text AI
  Days 29-30  Capstone project (text adventure, library system or AI classifier) + certificate
Every day: explanation, runnable examples, visualizer, guided practice, auto-checked
problems with several solutions, quiz, puzzle, review cards and notes.
