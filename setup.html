Setup and help

1. How Py30 works

Py30 runs a real Python 3.12 inside your browser — no installation needed. The first time you run code, the browser downloads Python (about 10 MB) and keeps it in its cache, so later visits are fast. Code that uses numpy or scikit-learn (Week 4) downloads those libraries the first time too.

Use a recent Chrome, Edge, Firefox or Safari, on a computer or a phone. An internet connection is needed to open the site.

2. Install Python on your own computer (recommended later)

You don't need it for the course, but after Day 30 you'll want to write programs on your own computer: download Python from python.org (on Windows tick "Add python.exe to PATH" on the first installer screen) and an editor like VS Code.

3. Your progress

Your name, solved problems, quiz scores, code and notes are saved in this browser on this computer. If you clear browser data or change browser, it is gone — so make a backup from time to time.

4. Using the code editors

  • Run (or Ctrl+Enter) runs your code. Check tests your solution automatically.
  • Visualize runs the code one line at a time and shows every variable.
  • Programs that use input() read from the Input box under the editor: one line per input().
  • Tab inserts 4 spaces. Reset brings back the original code.
  • The first run of the day takes a few seconds while Python wakes up. Code using numpy or sklearn loads those libraries the first time too.
